# 设计书模板（写程序前必须完成）

> 复制这个结构，写到 `output/design/<builder名>.md`。
> 构建时 `litematic.cjs run` 会自动校验：**缺设计书 → `design=BLOCK`，不生成**。
> 为什么强制：边写边想的代价是 6~8 轮返工，而结构级错误（桥接不上塔、塔成孤立体）
> 事后检测只给"12,214 悬空"，看不出根因。**先在纸面上算清楚，再动笔。**

> **坑**：同一个数在不同的"半径原点"下含义完全不同（从塔心朝中心量 vs 全局半径）。
> 每个数值都必须标清相对谁，否则桥会画到广场上、塔会变孤立体。

## 3. 构成（每个部件怎么长出来）

- 旋转体：剖面表 `[[层 y, 半径, 材质], ...]`，**并注明相邻层半径差 ≤ 壳厚**
- 立面：色带分布（基座 / 主体 / 顶带）、门窗位置规则
- 装饰：每件写清**靠什么承托**（下方 / 上方 / 侧面）

---

## 4. 预检算式（这一节必须有数字，≥8 行带数字）

- 越界检查：最远部件到中心 = ___ ≤ 画布半宽 ___ ？
- 层重叠：第 n 层内径 ___ 与第 n+1 层外径 ___ 是否重叠？
- 净空：室内高 ___ ≥ 2？主通道 ≥ 3？
- 门槛高差：室内地面 ___ − 室外地面 ___ = ___ ≤ 1？
- 宽高比：___ / ___ = ___
- 支撑：每件吊挂物上方有块？

## 7.5 与基准建筑的关系（P14：新建写差异，修改写基准）

**这一节是必需项。** 先声明模式：

- [ ] **新建建筑** → 填写"差异"，证明尺寸/配色/布局不是从旧文件抄的
- [ ] **修改已有建筑** → 填写"基准"，声明原 builder，参数**应当沿用**

### 若是新建

- 可比对象（已有 builder 或旧作品）：______
- 本件尺寸 `___ × ___ × ___` 凭什么是这个：______
- 与可比对象的**实质差异**（体量档位 / 平面逻辑 / 竖向构成 / 色阶策略）：______
- 若某项与旧作**确实相同**，为什么必须相同：______

### 若是修改

- 基准 builder：______（提交时用 `--base <文件名>`）
- **保留不变的参数**：尺寸 / 坐标系原点 / 塔心距 / 色值 / 色阶档位 / 布局常数
- **本次改动**：______（只列被要求改的）
- 是否动到无关参数：______（应当"否"）

> 允许复用方法与经验（剖面表、局部坐标系、5 档色阶、画序纪律）。
> 新建：禁止复用尺寸/色值/坐标/布局常数；修改：**必须**沿用它们。
> `check_reuse.cjs` 新建模式报警、`--base` 修改模式则把重合视为要求。
